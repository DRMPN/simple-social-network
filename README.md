## Overview

<overview>
simple-social-network is a user-friendly web application that enables seamless communication through features like authentication and messaging. Designed for individuals seeking a platform for social interactions, it ensures a structured environment for managing user engagement while promoting effective communication practices in a modern online context.
</overview>

## Core features

<corefeatures>

1. **User Management**: Handles user authentication, registration, and secure login functionalities.

2. **Communication Tools**: Facilitates messaging and displays historical interaction data.

3. **Frontend Integration**: Utilizes HTML templates for a user-friendly interface and enhanced experience.

4. **Containerization**: Employs Docker for consistent deployment and development across environments.

5. **Testing Framework**: Includes a placeholder for future testing, promoting best practices in code quality.

</corefeatures>

## Installation

Install simple-social-network using one of the following methods:

**Build from source:**

1. Clone the simple-social-network repository:
```sh
❯ git clone https://github.com/DRMPN/simple-social-network
```

2. Navigate to the project directory:
```sh
❯ cd simple-social-network
```

3. Install the project dependencies:


**Using `pip`** &nbsp;
[<img align="center" src="" />]()

```sh
❯ echo 'INSERT-INSTALL-COMMAND-HERE'
```


**Using `docker`** &nbsp;
[<img align="center" src="https://img.shields.io/badge/Docker-2CA5E0.svg?style={badge_style}&logo=docker&logoColor=white" />](https://www.docker.com/)

```sh
❯ docker build -t DRMPN/simple-social-network .
```
